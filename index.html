01 / 为何简单

双击打开，看完就关，不多一步

不需要导入素材，也不需要管理图库。简单看图只做一件事：把文件尽快、清楚地显示出来。

01

双击即看

关联图片与 PDF 后，双击文件直接打开；也可以把文件拖进窗口，或从空白界面选择「打开文件...」。

02

连续浏览

同一目录里的同类文件，用上一张 / 下一张或 ← → 就能一路看下去，不用反复回到资源管理器。

03

专注看图

没有编辑器与素材库的层层入口。滚轮缩放、双击全屏、翻页就是全部操作，启动快、占用小。

02 / 主要功能

看图片，看PDF，
每一步都顺手

从第一张到下一张，从整体到细节，常用动作都在手边，不必再为看图绕路。

下载后直接体验 →
01

多页文档和多页图片

PDF文档多页TIFF图像支持键盘 ↑ / ↓ 翻页。

  • 多页 TIFF
  • PDF
  • ↑ ↓ 翻页
02

常见与专业图片

从 PNG、JPEG、GIF、WebP 到 PSD、ICNS、HDR、DDS，日常截图与设计稿都能直接打开；另有 TIFF（多页）与 JPEG 2000。

  • 17 种常见格式
  • 多页 TIFF
  • JPEG 2000
03

连续浏览

同目录同类文件的上一张 / 下一张，左右方向键也能切换。看漫画、看截图、看一组素材，都不必退出重开。

  • 上一张 / 下一张
  • ← → 切换
  • 同目录识别
04

缩放与全屏

滚轮以鼠标位置为中心缩放，想看清哪里就放大哪里；双击切换全屏，状态栏的 − / + 可以手动微调比例。

  • 鼠标位置缩放
  • 双击全屏
  • 手动缩放
05

原始像素

直接查看 RGB24 / BGR24、RGBA32 / BGRA32 / ARGB32、RGB565、RGB555 / ARGB1555、RGB332、RGB48 / BGR48、RGB30 与 Planar RGB。

  • 打包像素
  • 平面排列
  • 文件名带尺寸
06

界面美观与系统集成

四种主题、多语言与窗口位置尺寸记忆；可配置文件关联与资源管理器右键菜单，也能随时在设置中关闭。

  • 四种主题
  • 多语言

07 / 更新记录

每一次更新，都让看图更顺一点

最近几个版本的变化。完整记录见项目 README。

  1. 0.5.6

    翻页箭头更清爽

    上下翻页按钮改为与上一张 / 下一张一致的透明箭头样式，去掉背景色与边框；四个方向箭头重新绘制，开口角度加大到 90° 以上。

  2. 0.5.5

    状态栏信息重排

    文件名移到主界面底部状态栏最左侧，状态栏按「文件名 → 大小 → 分辨率 → 格式」的顺序显示。

  3. 0.5.4

    恢复原生标题栏

    恢复系统原生标题栏，标题栏左侧显示「简单看图 v版本号」，当前文件名移到主界面底部状态栏的居中位置。

  4. 0.5.3

    窗口按钮贴近系统

    标题栏窗口按钮改为贴近 Windows 原生样式：46 × 34 点击区、10 px 图标，最小化为细横线、最大化为方框、关闭悬停红色。

  5. 0.5.2

    自绘标题栏

    左侧显示「简单看图 + 版本号」，当前文件名居中显示在同一行；支持拖动标题栏移动窗口、双击最大化 / 还原、拖动窗口边缘缩放。

  6. 0.4.6

    启动加速

    使用 AOT 缓存加速主界面启动，软件首次启动更快。
