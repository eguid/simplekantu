# 简单看图（SimpleKantu）

轻量、快速的 Windows 图片与PDF文档查看器。双击或拖入文件即可浏览，专注看图本身。

## 功能特性

- 常见图片：PNG、JPEG、GIF、BMP、WebP、ICO、CUR、PSD、ICNS、TGA、PCX、PNM、SGI、HDR、DDS、XBM、XPM
- 专业图像：TIFF（支持多页翻页）、JPEG 2000（jp2/j2k）
- 原始像素：RGB24/BGR24、RGBA32/BGRA32/ARGB32、RGB565、RGB555/ARGB1555、RGB332、RGB48/BGR48、RGB30、Planar RGB（GBRP）
- 矢量与文档：SVG/SVGZ、PDF、常见文本（只读）
- 连续浏览：同目录同类文件的上一张 / 下一张
- 看图交互：滚轮以鼠标位置缩放、双击切换全屏、左右方向键切换文件
- 多页 TIFF：内容区底部居中翻页，自动适配主题
- 四种主题、多语言、窗口位置与尺寸记忆
- 文件关联与资源管理器右键菜单（可随时在设置中关闭）
- 安装包与免安装绿色版

## 使用说明

- 双击图片 / PDF 文件打开，或直接把文件拖入窗口
- 空白界面可点击“打开文件...”选择一个或多个文件
- 滚轮缩放、双击进入或退出全屏、`←` / `→` 切换上一张 / 下一张
- 在内容区右键：查看图片属性、设置、使用说明、关于、关闭窗口

原始像素文件：文件名中包含尺寸即可直接打开，例如 `photo_1920x1080.rgb24`；没有尺寸时，打开后会提示输入宽高。

## 系统要求

Windows 10 / 11（64 位）
